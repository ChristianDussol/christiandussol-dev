# Community

Giving some time back to the communities I learned from.

Most of this site is work I decided to publish. This page is work other people asked for: reading talk proposals, shaping a programme, reviewing someone else's architecture before they ship it.

None of it scales, and that is rather the point. The cloud-native ecosystem runs on volunteers reviewing each other's work, and I had years of benefit from that before I started contributing any of it back.

Each entry below gives the role, the organisation, the dates, and what the work actually involves.
